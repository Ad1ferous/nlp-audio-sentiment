# Задание 1. Описание датасета

**Кейс:** 2 — анализ тональности (позитив / негатив)
**Дисциплина:** Обработка естественного языка, УрФУ
**Датасет:** [WB Review Dataset — Russian E-commerce Sentiment](https://www.kaggle.com/datasets/vladkapitsa/wb-review-dataset-russian-e-commerce-sentiment)

## 1. Состав датасета

Скачали `filtered.csv` с Kaggle. Исходно: **27 248 отзывов, 9 колонок**:
`review_id`, `product_id`, `category`, `category_label`, `rating`, `text`, `pros`, `cons`, `date`. `rating` (1–5) — это и есть целевой сигнал.

Категорий товаров — **7**. Самая большая — «Косметика и уход» (5 567), самая маленькая — «Продукты питания» (2 440).

В `text` было 7 689 пропусков (28%), но в этих строках часто заполнены `pros` и/или `cons`. Объединили все три поля в один текст — восстановили **все 7 689 строк**, пустых текстов не осталось.

После отбрасывания нейтральных (оценка 3) осталось **24 968 отзывов**. Дубликатов нет.

## 2. Классы

Переделали `rating` в бинарную метку: 4–5 → позитив (1), 1–2 → негатив (0), 3 → отбрасываем.

- позитив: 20 403 (81.72%)
- негатив: 4 565 (18.28%)

Классы сильно несбалансированы — позитива в 4.5 раза больше. Посчитали `class_weight` ≈ `{0: 2.735, 1: 0.612}`, будем использовать при обучении, чтобы модель не угадывала всё как позитив.

Распределение оценок:

| Оценка | Кол-во | Доля |
|---|---|---|
| 1 | 3 385 | 12.42% |
| 2 | 1 180 | 4.33% |
| 3 | 2 280 | 8.37% |
| 4 | 2 928 | 10.75% |
| 5 | 17 475 | 64.13% |

## 3. Качество данных

Тексты не нормализованы: есть опечатки («Саветую», «Афигенные»), разговорные формы, сокращения. Для отзывов это нормально, но перед обучением придётся почистить.

**Проверка шума.** Простой тест: если у позитивного отзыва в тексте есть негативные слова («ужас», «плохо», «брак») — подозрительно, и наоборот. Получилось 1 205 таких позитивных (4.83%) и 631 негативный (2.53%), итого ≈ **7.35% шумных**. Это оценка сверху — бывают смешанные отзывы вроде «доставили быстро, но брак».

Пример явной ошибки — оценка 1, а текст позитивный:
> «Пришло в хорошей упаковке, зарядное устройство почти на полной зарядке… Рекомендую производителя.»

Из-за такого шума потолок accuracy у модели ≈ 96–97%, даже если она идеально выучит данные.

**Длина текстов:** средняя 227 символов / 34 слова, медиана 189 символов / 28 слов. Минимум 57 символов — коротких мусорных текстов нет.

## 4. Качество транскрипций

**Пока не применимо** — датасет текстовый. Транскрипции появятся, когда начнём синтезировать аудио из этих текстов через TTS. Оценивать будем потом — сравним распознанный ASR-текст с исходным.

## 5. Зачем нам этот датасет

Задание требует русскоязычные данные. Здесь язык русский, разметка есть, тексты короткие — всё, что нужно. Короткие отзывы по стилю похожи на устные сообщения: прогнав их через TTS, получим аудио для обучения классификатора голосовых.

**План по объёму для TTS.** Если синтезировать все 24 968 отзывов, по нашей оценке (~2.5 слова/сек) выйдет ≈ **96 часов** аудио — слишком много. Поэтому сделали сбалансированную подвыборку:

- 4 000 фраз (2 400 позитив / 1 600 негатив, ~60/40);
- стратифицировали по категориям;
- seed = 42, чтобы у всей команды выборка была одинаковая;
- оценка синтеза ≈ **12.45 часов** — реалистично;
- сплиты: train 2 800 / val 600 / test 600.
