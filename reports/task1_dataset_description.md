## 2. Качество данных

### Нормализация и технические параметры

- Текст **не нормализован**: содержит опечатки («Саветую», «Афигенные»), разговорные формы, эмодзи (в некоторых отзывах).
- Пропуски: `text` — 7 689 (28.2%), `pros` — 13 672 (50.2%), `cons` — 18 836 (69.1%).
- **Восстановление текста:** 100% строк с пустым `text` были заполнены из `pros`/`cons`, итоговый пустой `full_text` — 0.

### Распределение оценок

| Оценка | Кол-во | Доля |
|---|---|---|
| 1 | 3 385 | 12.42% |
| 2 | 1 180 | 4.33% |
| 3 | 2 280 | 8.37% |
| 4 | 2 928 | 10.75% |
| 5 | 17 475 | 64.13% |

**Целевая переменная (бинарная тональность):**
- Позитив (rating 4–5): **20 403** (81.72%)
- Негатив (rating 1–2): **4 565** (18.28%)
- Нейтральные (rating 3) отброшены: 2 280

**Рекомендуемые `class_weight` для обучения:** `{0: 2.735, 1: 0.612}`

### Объективная оценка качества

Оценка шума разметки выполнена эвристикой по маркерам тональности:
- Позитивных с негативными маркерами: **1 205** (4.83%)
- Негативных с позитивными маркерами: **631** (2.53%)
- **Итого потенциально шумных: ≈ 7.35%**

Это верхняя граница шума — часть маркеров попадает в смешанные отзывы. Реальная доля ошибок ниже. Пример явной ошибки разметки:

> «Пришло в хорошей упаковке, зарядное устройство почти на полной зарядке, проверила дома на телефонах все заряжается… Рекомендую производителя.» — `rating = 1`

Такой шум ограничивает потолок accuracy ~96–97%.

## 4. Применимость для задачи

Датасет подходит для кейса 2 по следующим причинам:

1. **Язык — русский**, что соответствует требованиям кейса.
2. **Разметка `rating` (1–5)** напрямую конвертируется в бинарную тональность: 4–5 → позитив, 1–2 → негатив.
3. **Тексты короткие и разговорные** (медиана 28 слов), по стилю близки к устным сообщениям. После TTS-синтеза получаем аудио, релевантное задаче классификации голосовых сообщений.
4. **Достаточный объём** (24 968 объектов) для обучения и валидации.
5. **Разметка из объективного сигнала** (оценка покупателя), что снижает шум по сравнению с ручной разметкой.

### TTS-бюджет

| Параметр | Значение |
|---|---|
| Оценка длительности синтеза полного датасета | ≈ 96 часов |
| Размер стратифицированной подвыборки для TTS | 4 000 фраз |
| Баланс классов в подвыборке | 2 400 позитив / 1 600 негатив (60/40) |
| Оценка длительности синтеза подвыборки | ≈ 12.45 часов |
| Сплиты | train 2 800 / val 600 / test 600 |
| Seed фиксации | 42 |

Полный TTS-синтез 96 часов нецелесообразен. Сформирована подвыборка `tts_sample.csv` (4 000 строк, стратифицирована по категориям, seed=42), которая используется для обучения аудио-классификатора в итоговом ДЗ.
