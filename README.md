# NLP Audio Sentiment — Telegram Voice Messages

Классификация тональности аудио-сообщений из Telegram (позитив / негатив).
**Кейс 2:** «Анализ тональности: классификация отзывов как позитивных, негативных или нейтральных».

**Дисциплина:** Обработка естественного языка, УрФУ, 3 семестр ПИИ.
**Команда:** _впишите ФИО участников_

## Описание задачи

На вход подаются голосовые сообщения из Telegram. На выход — метка тональности:
- `0` — негатив
- `1` — позитив
- (нейтральный класс планируется на этапе развития проекта)

Усложнение задачи: TTS-синтез аудио из текстовых отзывов для обогащения тренировочного датасета.

## Датасет

WB Review Dataset — Russian E-commerce Sentiment
🔗 [kaggle.com/datasets/vladkapitsa/wb-review-dataset-russian-e-commerce-sentiment](https://www.kaggle.com/datasets/vladkapitsa/wb-review-dataset-russian-e-commerce-sentiment)

- **Исходный объём:** 27 248 отзывов × 9 колонок
- **После очистки:** 24 968 отзывов (позитив 81.72% / негатив 18.28%)
- **Категорий товаров:** 7
- **Шум разметки:** ≈ 7.35% (оценка по маркерам)

Подробное описание датасета — в [`reports/task1_dataset_description.md`](reports/task1_dataset_description.md).
