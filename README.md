# NLP Audio Sentiment — тональность голосовых отзывов из Telegram

Учебный проект по дисциплине «Обработка естественного языка» (УрФУ).

**Кейс 2:** система принимает голосовые из Telegram и определяет тональность — позитив или негатив.

## Задача

На вход — аудио-сообщение. На выход — метка:
- 0 — негатив
- 1 — позитив

Нейтральный класс пока не используем, добавим позже. Дополнительно хотим попробовать TTS: синтезировать аудио из текстовых отзывов, чтобы расширить датасет.

## Датасет

Взяли [WB Review Dataset — Russian E-commerce Sentiment](https://www.kaggle.com/datasets/vladkapitsa/wb-review-dataset-russian-e-commerce-sentiment) с Kaggle.

Почему он подходит:
- русский язык — как требует задание;
- оценка отзыва (1–5) превращается в метку: 4–5 → позитив, 1–2 → негатив;
- тексты короткие, похожи на устную речь — потом можно синтезировать из них аудио;
- разметка от покупателей (их оценка), а не ручная — шума меньше.

Основные цифры:
- исходно: 27 248 отзывов, 9 колонок;
- после очистки: 24 968 отзывов;
- позитив 81.72%, негатив 18.28%;
- категорий товаров: 7.

Подробнее — в [reports/task1_dataset_description.md](reports/task1_dataset_description.md).
